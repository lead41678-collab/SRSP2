# СРСП № 2 — Условные операторы C#

15 консольных приложений по практикуму. Выполнены основные задания и все дополнительные действия № 1–10.

## Запуск в Visual Studio

1. Откройте `SRSP2.sln` в Visual Studio с поддержкой .NET 10 и компонентами разработки .NET.
2. Раскройте папку «Часть 1» (№ 1–10) или «Часть 2» (№ 11–15).
3. Нажмите правой кнопкой на нужном проекте → «Назначить запускаемым проектом».
4. Нажмите Ctrl+F5, затем введите запрошенные данные.

Каждый проект создан по шаблону Console App, работает независимо и содержит свой `Program.cs`.
Используются `if`, `else if`, `else`, `switch`, проверка ввода через `int.TryParse`.
В задании 14 ответы вводятся русскими буквами А, Б, В (регистр не важен).
Задание 8 только имитирует операции с файлами.

## Проверка

Сборка: `dotnet build SRSP2.sln`.

Автоматическая проверка: `powershell -ExecutionPolicy Bypass -File tests/Verify.ps1`.
Проверка запускает собранные приложения с разными входами и сравнивает вывод.
