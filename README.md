# СРСП № 2 — Условные операторы C#

Один консольный проект `SRSP2.csproj`, один файл с кодом `Program.cs` и все 15 заданий, включая дополнительные действия № 1–10.

## Запуск

1. Откройте `SRSP2.sln` в Visual Studio с поддержкой .NET 10.
2. Нажмите Ctrl+F5.
3. Введите номер задания от 1 до 15 и затем запрошенные данные.
4. После выполнения задания программа возвращается в меню. Введите 0 для выхода.

В меню и в Program.cs сохранено разделение на «Часть 1» (№ 1–10) и «Часть 2» (№ 11–15).
В коде задания оформлены отдельными методами Task01–Task15 внутри того же файла; разделы можно свернуть через #region.
В задании 14 вводите русские буквы А, Б, В. Задание 8 только имитирует операции с файлами.

## Проверка

Сборка: `dotnet build SRSP2.sln`.

Запуск из терминала: `dotnet run --project SRSP2.csproj`.

Автоматические проверки: `powershell -ExecutionPolicy Bypass -File tests/Verify.ps1`.
Проверяются задания через главное меню, ошибки ввода, границы, выход и повторный выбор заданий.
